| key | type | meaning |
|---|---|---|

| name | string | Description (trimmed, original case) |
| system | string | derived trade: HVAC, Fire safety, Electrical, Plumbing, Water treatment, Lifts, Kitchen, Solar, Pool, Appliances, Building fabric, Furniture, IT & AV, Lab equipment, Sports, General |
| category | string | register Category: Equipment, Building, Furniture Fixture, House equipment, Furniture |
| building | string | Building Name |
| location | string | Location / Area |
| room | string | Room No. |
| model | string | |
| serial | string | Identification # S.No |
| tag | string | Asset Tag # |
| qty | number | units this entry covers (summed when identical rows are merged) |
| year | number | Year of Purchase |
| life | number | life cycle (years) |
| lifePct | number | % operational life, 0..1+ |
| criticality | string | "Critical" (C) or "Non-critical" (NC) |
| amc | string | "" or frequency label, e.g. "Quarterly" when AMC = Y |
| ppm | string | "" or frequency label when Covered under PPM = Y |
| freq | number | PM interval days: PPM freq else AMC freq (M 30, Bi 60, Q 90, H 180, Y 365); Furniture 365; others 180 |
| src | string | sheet + Excel row(s), e.g. "Asset Master List r6" or "Asset Master List r120-r123" |
